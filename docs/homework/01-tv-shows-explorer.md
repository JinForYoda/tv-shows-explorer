# Homework #1 — TV Shows Explorer

Небольшое приложение для поиска и просмотра сериалов через публичный API TVmaze.

## 1. Поиск шоу

Список шоу берём из `https://api.tvmaze.com/search/shows?q=banana`, где `q` — любой поисковый запрос.

- Сначала приложение показывает только поле поиска и пустой список.
- Пользователь вводит запрос, приложение получает результаты от TVmaze.
- Фильтрацию по запросу выполняет сам API.

## 2. Список и пагинация

- Шоу отображаются списком или карточками.
- Пагинация: 3 элемента на страницу, можно переключаться между страницами.

## 3. Фильтрация по жанрам

- Над списком — все уникальные жанры текущей выдачи в виде кликабельных chips.
- Выбор жанра оставляет только шоу этого жанра.
- Фильтр можно сбросить и вернуться ко всем результатам.

Пример: запрос `Murder` вернул 10 шоу. Клик по `Comedy` оставляет только 2 комедии.

## 4. Дополнительно

- Дизайна нет, оформление выбираем сами.
- Продумать UX: не слать запрос на каждую букву, отменять устаревшие запросы, показывать загрузку и ошибки.
- Challenge (по желанию): работа с запросами без `useQuery`. В этом проекте используем `useQuery`.
